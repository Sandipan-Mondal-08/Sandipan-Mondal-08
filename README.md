# Hi, I'm Sandipan Mondal 👋

M.Sc. Bioinformatics graduate of the **Bioinformatics Centre, Savitribai Phule Pune University**, now at Chanakya University, Bangalore. I work on computational drug discovery against drug-resistant tuberculosis.

## What I work on
- Structure-based virtual screening and molecular docking
- Molecular dynamics and binding free energy (MM/GBSA, MM/PBSA)
- Data analysis and visualisation in Python

## Featured project

### [InhA inhibitors for *M. tuberculosis*](https://github.com/Sandipan-Mondal-08/inha-hydrazinyl-pyrrole-dione-tb)
15 hydrazinyl pyrrole dione derivatives screened against InhA. Two leads (PS276, PS291) bind more strongly than the native ligand in MM/GBSA.
